# Ноутбуки

Каталог предназначен для исследовательских и экспериментальных ноутбуков.

## Именование

Используйте формат `NN-фамилия-тема.ipynb`, например `01-ivanov-docx-parsing.ipynb`. Каждый участник изменяет только свои ноутбуки.

## Подготовка изменений

- Выводы ячеек удаляются автоматически хуком `nbstripout`.
- Логику, которая нужна больше одного раза, следует перенести в `src/` отдельным PR.

Полные правила работы с репозиторием приведены в [CONTRIBUTING.md](../CONTRIBUTING.md#ноутбуки).
