# Архитектурные решения (ADR)

Короткие заметки по одному на решение: **контекст → решение → альтернативы → последствия**.
Статус «предложено» означает, что решение еще не утверждено командой.

## Шаблон

Файл `NNNN-<короткое-название>.md`, например `0006-llm-provider.md`.

```markdown
# ADR-0006: LLM-провайдер

- Статус: предложено / принято / заменено ADR-XXXX
- Дата: 2026-11-01
- Участники: ...

## Контекст
Что за проблема, какие ограничения.

## Решение
Что выбрали.

## Рассмотренные варианты
Какие варианты рассмотрели, их плюсы и минусы.

## Последствия
Что это даёт и чем придётся заплатить.
```
