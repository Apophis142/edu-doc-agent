# Архитектурные решения (ADR)

Короткие заметки по одному на решение: **контекст → решение → альтернативы → последствия**.
Полстраницы — достаточно. К концу семестра это готовый материал для главы отчёта.

## Шаблон

Файл `NNNN-<коротко>.md`, например `0003-pgvector.md`.

```markdown
# ADR-0003: Векторное хранилище — pgvector

- Статус: предложено / принято / заменено ADR-XXXX
- Дата: 2026-10-15
